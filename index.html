为什么比脚本更好？

• 不用管操作系统：无论是 Windows 还是 macOS 都能直接运行。

• 零权限拦截：彻底告别 macOS 的「已损坏/无法打开」及终端 chmod +x 门槛。

• 无任何上传：所有文本替换、打包均在你的浏览器内存中即时完成。

📂

选择本地 Android res 或 i18n 目录

直接选择包含 values/、values-*/ 的工程目录。点击后浏览器将请求该目录的读写权限。

* 支持 Chrome, Edge 等 Chromium 内核浏览器。若使用 Safari/Firefox 请切换到「ZIP 包导入导出」标签。
